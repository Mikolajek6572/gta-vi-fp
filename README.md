# GTA VI FunPage

Nieoficjalna strona fanowska poświęcona Grand Theft Auto VI: bohaterowie, Leonida i Vice City, fabuła z ukrywaniem spoilerów, ciekawostki, galeria, devlog, quiz, ciekawostka dnia, licznik od premiery i licznik czasu gry.

**Strona:** https://mikolajek6572.github.io/gta-vi-fp/

Czysty HTML5 + CSS3 + JavaScript (`index.html`, `style.css`, `script.js`), bez bibliotek.

Własne screeny do galerii dodasz w tablicy `GALLERY` w `script.js`:

```js
{ src: "img/moj-screen.jpg", title: "Tytuł", caption: "Opis", cat: "miasto" }
```
